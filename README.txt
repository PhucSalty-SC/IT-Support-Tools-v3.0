YÊU CẦU HỆ THỐNG:
  - Windows 10 / Windows 11
  - .NET Framework 4.8 (có sẵn trên Win 10 1903+)
  - Kết nối Internet (để tải tool và phần mềm)
  - Quyền Administrator

CHỨC NĂNG CHÍNH:
  [Dashboard]     Quick action 1-click cho tác vụ phổ biến
  [Driver Suite]  Tải & chạy SDIO quét driver tự động
  [Phần Mềm]      Cài Chrome, EVKey, Office 365, 7-Zip, VLC ngầm
  [Tối Ưu]        Tắt BitLocker, reset máy in, dọn temp, SFC
  [Mạng]          Flush DNS, reset TCP/IP, ping test, renew IP
  [System Info]   Kiểm tra bản quyền, thông số CPU/RAM/Disk

THƯ MỤC LÀM VIỆC:
  C:\IT_Tools\SDIO\   - Snappy Driver Installer
